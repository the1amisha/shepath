# Sharing a planned route

Open **View route overview** after selecting a walking or driving route. In **Share or save**, expand the preview to review the locations, travel time, departure and estimated arrival before sharing.

**Share on WhatsApp** prepares a message and a ShePath link. The recipient can open the link to view the selected path. The URL fragment contains the route geometry and trip details, so anyone who receives it can view the plan. The map shows a snapshot taken when the link was generated. Live location updates and turn-by-turn navigation are unavailable.

**Save as PDF** opens a printable tab. Choose **Print / save as PDF** to save it on the device. The PDF includes the selected route outline, start and destination markers, up to three available mapped landmarks, and a preference explanation when applicable. The outline is embedded and can be viewed offline.

Changing the trip updates future exports. To share a revised departure or route, send a new snapshot.
